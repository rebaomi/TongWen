# 晓譯 XiaoYi — AI 閱讀翻譯助手

> 專注網頁與學術 PDF 翻譯，整合 AI 對話、文字標注、截圖分析，支援 14 個主流翻譯/AI 引擎。

## ✨ 核心功能

### 🌐 網頁翻譯

| 模式 | 說明 |
|------|------|
| 📖 雙語對照 | 原文下方插入譯文，保留原版式 |
| 🔄 全文替換 | 直接替換頁面文字為譯文 |
| 🖱️ 劃詞翻譯 | 選取文字即時彈出翻譯氣泡 + 「問 AI」按鈕 |

- **快捷鍵**：`Alt+T` 翻譯當前頁，`Alt+M` 切換翻譯模式
- **右鍵選單**：翻譯選取文字、整頁、連結頁面
- **懸浮操作面板**：可拖曳面板，一鍵存取所有功能（可在設定中開啟）
- **動態內容支援**：MutationObserver 自動翻譯頁面後續載入的內容
- **智慧跳過**：自動跳過程式碼區塊、輸入框等不適合翻譯的區域
- **翻譯快取**：會話級快取，相同內容瞬間回傳
- **失敗自動重試**：網路不穩時最多重試 2 次

### 📄 學術 PDF 翻譯

- 📐 **自動識別並保留 LaTeX 數學公式**（`$...$`、`$$...$$`、`\begin{}` 環境）
- 📖 **保留參考文獻引用標記**（`[1]`、`(Author 2020)` 等）
- 🗂️ **雙欄版面自動偵測**：正確處理學術論文的雙欄排版
- 📄 **段落級雙語對照**：按段落合併翻譯，格式與原文一致
- 📏 **頁碼範圍翻譯**：只翻譯指定頁，大幅節省 API 用量
- 💾 **進度自動儲存**：中途關閉後可恢復翻譯進度
- 🔗 **支援網路 PDF 直連**：貼上 arXiv 等連結直接載入
- 📥 **匯出雙語 PDF**：原文頁 + 譯文頁交替排列

### 🤖 AI 閱讀助手

- **AI 側邊欄**：頁面右側全螢幕聊天面板，支援串流輸出，可注入當前頁面內容作為上下文
- **視覺分析**：截圖發送給 AI 分析圖表、表格、流程圖等
- **選取問 AI**：選取任意文字 → 彈出工具列 → 一鍵翻譯或發給 AI 深度解讀
- **劃詞問 AI**：懸浮翻譯氣泡底部附帶「問 AI」按鈕，無縫銜接深度解讀
- **高亮標注**：5 種顏色標注重要內容，持久化儲存，重新整理後自動恢復
- **框選截圖**：一鍵截取頁面任意區域並自動發給 AI 分析

### ⚙️ 進階設定

- **自訂術語表**：填寫專業術語的固定譯法，翻譯結果自動替換
- **按網域設定**：為不同網站單獨設定引擎、翻譯模式或完全停用
- **排除網域**：在指定網站上完全關閉所有翻譯功能（即時生效，無需重新整理）

## 🔒 安全設計

- API Key 儲存於本地 `chrome.storage.local`，**不同步到雲端**
- 內容腳本無法直接取得 API Key，Key 僅在 Service Worker 記憶體中短暫使用
- Service Worker 驗證訊息來源，拒絕非法呼叫

## 🚀 快速開始

```bash
npm install
npm run build
```

1. 開啟 `chrome://extensions/`
2. 開啟「開發人員模式」
3. 點擊「載入未封裝項目」
4. 選擇專案目錄下的 **`dist/`** 資料夾
